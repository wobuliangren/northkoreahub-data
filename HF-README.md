# North Korea Hub — Open Dataset

Live, dual-source-verified data on **who can enter North Korea (DPRK) and how the rules change**, maintained by [northkoreahub.com](https://northkoreahub.com) — the public access-rules ledger for North Korea.

## Contents
- `access.json` — tourist-access status by nationality (9 entries), each with sources and a last-verified date
- `changes.json` — the rule-change timeline (16 entries)
- `access-by-nationality.csv`, `changes.csv` — the same data in CSV

## Use
Free to use with attribution (CC BY 4.0). Live API: https://northkoreahub.com/api/v1/access.json and /api/v1/changes.json — always fresher than this snapshot. Method: https://northkoreahub.com/about/method/
